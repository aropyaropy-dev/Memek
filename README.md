# IP Rotator Android — GitHub starter

Upload all files and folders in this ZIP to the root of your GitHub repository, preserving paths. Commit to `main`, then open **Actions** and run **Build IP Rotator APK**. After a successful run, download the `IPRotator-debug-apk` artifact.

**Important:** This is a buildable starter shell, not a working IP-rotation VPN. It does not yet connect to VPN endpoints or change the public IP. Real public-IP rotation requires multiple working VPN/proxy servers, valid configurations, and an implemented VPN backend. Do not publish VPN private keys or credentials.
